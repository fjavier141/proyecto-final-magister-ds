# proyecto-final-magister-ds

### **Python recomendado**
- **Python 3.12**

---

### **Variables de entorno necesarias**

Debes definir las siguientes variables antes de ejecutar el proyecto.  
*(Valores reemplazados por ejemplos dummy; ajusta según tu entorno real.)*

```bash
POSTGRES_USER=postgres_user
POSTGRES_PASSWORD=postgres_password
POSTGRES_HOST=127.0.0.1
POSTGRES_PORT=5432
POSTGRES_DB=postgres_db
```

---

### **Instalar dependencias**

Asegúrate de tener todas las librerías necesarias:

```bash
pip install -r requirements.txt
```

---

### **Orden de ejecución del proyecto**

1. **Preprocesamiento**  
   `src_main/src_preprocessing/main.py`

2. **Entrenamiento y validación del modelo**  
   `src_main/src_train_val/main2.py`
